# CORTHAL: Cryptography & Secrets Specification

## 1. Zero-Knowledge Cryptographic Model
Corthal использует асимметричное шифрование на базе существующего SSH-ключа пользователя:
* **Публичный ключ**: `~/.ssh/id_ed25519.pub` (или указанный пользователем).
* **Приватный ключ**: `~/.ssh/id_ed25519` (защищен пасс-фразой).

Стандарт шифрования: **Age (Actually Good Encryption)** с нативной поддержкой SSH-ключей (крейт `age` на Rust).

---

## 2. Token Format (Формат зашифрованного токена)
В Markdown-файлах секреты хранятся в виде встроенного кода:
```text
`🔒[enc:v1:AGE-PAYLOAD]`
```

Где:
* `🔒[enc:` — неизменный префикс-маркер для парсера.
* `v1` — версия протокола шифрования.
* `AGE-PAYLOAD` — результат шифрования строки в формате Age Armor (Base64-совместимый).
* `]` — закрывающий маркер.

---

## 3. Cryptographic Operations (Операции)

### 3.1. Шифрование (Encryption / Pre-Send)
* **Вход**: Открытая строка `plaintext`, путь к публичному ключу `id_ed25519.pub`.
* **Требование к пасс-фразе**: **НЕ ТРЕБУЕТСЯ**.
* **Процесс**:
  1. Загрузка SSH-ключа получателя через `age::ssh::Recipient::from_str(...)`.
  2. Шифрование потока данных в armored-строку.
  3. Упаковка в токен: `format!("`🔒[enc:v1:{}]`", armored_data)`.
* **Быстродействие**: < 2 мс.

### 3.2. Расшифровка (Decryption / Render)
* **Вход**: Токен `🔒[enc:v1:...]`, путь к приватному ключу `id_ed25519`, пасс-фраза (или дескриптор `ssh-agent`).
* **Процесс**:
  1. Извлечение `AGE-PAYLOAD` из токена.
  2. Загрузка `age::ssh::Identity::from_buffer(..., Some(passphrase))`.
  3. Дешифрование в `plaintext`.
* **Безопасность памяти**: Расшифрованная строка живет исключительно в UI-памяти виджета и не сохраняется на диск.
