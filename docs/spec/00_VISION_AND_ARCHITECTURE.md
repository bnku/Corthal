# CORTHAL: Vision & Architecture Specification

## 1. Vision (Видение проекта)
**Corthal** — это персональный легковесный Desktop-клиент для локальной базы знаний («Второго мозга») на Linux, объединяющий:
1. **Быстрый навигатор и редактор Markdown**: прямое чтение и запись файлов из `~/knowledge/` без проприетарных форматов.
2. **Zero-Knowledge хранилище секретов на базе SSH-ключа**: бесшовное шифрование чувствительных данных (паролей, токенов) с использованием публичного ключа `~/.ssh/id_ed25519.pub` и расшифровкой через приватный ключ `~/.ssh/id_ed25519`.
3. **Интегрированный ИИ-ассистент с защитой от утечек**: локальный перехват и шифрование секретов до отправки промпта внешним LLM, позволяющий безопасно поручать агентам организацию конфигов и заметок.

## 1.1. Происхождение названия (Naming & Etymology)
Название **Corthal** (*Ко́р-тал*) выбрано как уникальное имя, отражающее суть «Второго мозга» и структуру приложения:
* **Cor**tex (*кора головного мозга*) — хранилище долговременной памяти, концепций, смысловых связей и знаний.
* **Thal**amus (*таламус*) — центральный информационный хаб и маршрутизатор мозга, связывающий все области коры воедино и распределяющий потоки данных по функциональным зонам (аналог архитектуры Хабов в базе знаний: `00-Inbox`, `10-System`, `20-Work`, `30-Life`, `40-Resources`).
* Созвучие со словом **Portal** (*портал*) подчеркивает роль приложения как быстрой и чистой точки входа в персональное цифровое хранилище.

## 2. Core Principles (Базовые принципы)
* **Local-First & Zero Lock-in**: Все заметки — стандартные `.md` файлы в файловой системе. Никаких баз данных, блокирующих пользователя внутри приложения.
* **Zero-Knowledge для внешних LLM**: Ни один открытый пароль никогда не попадает в контекст языковой модели. Агент видит только неделимые зашифрованные токены `🔒[enc:v1:...]`.
* **Легковесность и производительность**: Стек **Tauri v2 + Rust + Svelte** гарантирует потребление памяти < 50 МБ RAM и мгновенный холодный старт (в отличие от Electron-аналогов).
* **Spec-Driven Development (SDD)**: Любая разработка, рефакторинг и расширение функционала ведутся строго по спецификациям в `docs/spec/`.

## 3. High-Level Architecture (Архитектурная схема)

```text
┌────────────────────────────────────────────────────────┐
│                   FRONTEND (Svelte 5 + TS)             │
│  - Vault Explorer (навигация по хабам 00-90)          │
│  - Markdown Viewer / Editor                           │
│  - Secret Widget (••••••••, Copy, Reveal)              │
│  - Assistant Panel (Chat, pre-send {{secret:...}} enc) │
└───────────────────────────▲────────────────────────────┘
                            │  Tauri IPC (Events / Commands)
┌───────────────────────────▼────────────────────────────┐
│                    BACKEND (Rust Core)                 │
│                                                        │
│  [corthal::vault]  - сканирование и FS-watcher         │
│  [corthal::crypto] - age + SSH ed25519 шифрование      │
│  [corthal::ai]     - адаптер агентов / Antigravity CLI │
└───────────────────────────▲────────────────────────────┘
                            │  Файловая система
┌───────────────────────────▼────────────────────────────┐
│  - ~/knowledge/ (Заметки и Хабы)                       │
│  - ~/.ssh/id_ed25519(.pub) (Ключи шифрования)          │
└────────────────────────────────────────────────────────┘
```
