# CORTHAL: Roadmap & Task Tracker (SDD)

> Данный документ является официальным трекером дорожной карты и задач проекта Corthal в соответствии с методологией Spec-Driven Development (SDD).

---

## 🎯 Общий статус направлений

| Направление / Майлстоун | Статус | Приоритет | Описание |
| :--- | :---: | :---: | :--- |
| **Milestone 1: Obsidian UX & Metadata Engine** | 🚀 **В РАБОТЕ** | P0 (Текущий) | Метаданные `.meta.json`, динамические хабы, человекочитаемое сворачиваемое дерево, блок Obsidian Properties, вставка секретов. |
| **Milestone 2: Live FS Watcher & Full-Text Search** | ⏳ Отложено | P1 (Следующий) | Мониторинг файловой системы на Rust (`notify`), полнотекстовый поиск по содержимому заметок. |
| **Milestone 3: AI Assistant Engine & Tools** | ⏳ Отложено | P1 (После M2) | Интеграция LLM (API / Antigravity CLI / локальная модель), Function Calling (`vault_*`), голосовой ввод. |
| **Milestone 4: Rsync Backup System** | ⏸️ Вне приложения | P2 (Отдельно) | Автоматизация резервного копирования базы на внешние/соседние диски (системный уровень). |
