# CORTEX: Roadmap & Task Tracker (SDD)

> Данный документ является официальным трекером дорожной карты и задач проекта Cortex в соответствии с методологией Spec-Driven Development (SDD).

---

## 🎯 Общий статус направлений

| Направление / Майлстоун | Статус | Приоритет | Описание |
| :--- | :---: | :---: | :--- |
| **Milestone 1: Obsidian UX & Metadata Engine** | 🚀 **В РАБОТЕ** | P0 (Текущий) | Метаданные `.meta.json`, динамические хабы, человекочитаемое сворачиваемое дерево, блок Obsidian Properties, вставка секретов. |

## 📋 Milestone 1: Obsidian UX & Metadata Engine (Текущий спринт)

- [ ] **1.1. Метаданные папок (`.meta.json`) и динамические хабы**:
  - [ ] Разработать структуру `.meta.json` (title, icon, order, color, description).
  - [ ] Обновить бэкенд `vault.rs`: парсинг `.meta.json` в `VaultNode`.
  - [ ] Создать базовые `.meta.json` в `~/knowledge/` (`00-Inbox`, `10-System`, `20-Work`, `30-Life`, `40-Resources`, `90-Archive`).
  - [ ] Убрать хардкод списка хабов в Svelte, генерировать вкладки динамически из корневых `VaultNode`.
- [ ] **1.2. Человекочитаемое и сворачиваемое дерево заметок (Obsidian File Explorer)**:
  - [ ] Извлечение `title` из YAML frontmatter (или первого заголовка `# ...`) для файлов `.md`.
  - [ ] Отображение человекочитаемых названий в `VaultTree.svelte` с тултипом реального пути.
  - [ ] Сворачивание/разворачивание папок по умолчанию (начальное состояние: свернуты или только активный хаб).
  - [ ] Шевроны `▶` / `▼` и плавная анимация.
  - [ ] Автораскрытие дерева до выбранной активной заметки.
  - [ ] Кнопка «Свернуть все» в шапке файлового проводника.
- [ ] **1.3. Интерактивный блок свойств заметки (Obsidian Properties)**:
  - [ ] Парсинг YAML frontmatter на фронтенде с исключением его из markdown-тела.
  - [ ] Компонент `PropertiesBlock.svelte`:
    - [ ] Теги-пилюли (кликабельные для фильтрации).
    - [ ] Статус заметки (светофор: active, draft, verified, deprecated).
    - [ ] Дата создания/изменения.
    - [ ] Дополнительные произвольные поля в аккуратной таблице свойств.
    - [ ] Кнопка сворачивания/разворачивания блока свойств.
- [ ] **1.4. Инструменты создания и редактирования заметок**:
  - [ ] Кнопка создания новой заметки в выбранной папке (`+ Новая заметка`).
  - [ ] Модальное окно или быстрая кнопка «+ Секрет» в редакторе: локальное шифрование введенного пароля публичным SSH-ключом и вставка `🔒[enc:v1:...]`.
  - [ ] Тестирование и верификация в живом приложении (скриншот).
