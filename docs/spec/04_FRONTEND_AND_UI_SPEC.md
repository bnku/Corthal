# CORTHAL: Frontend & UI Specification

## 1. UI Layout (Трехпанельный макет)
Интерфейс разделен на 3 адаптивные колонки:
1. **Left Sidebar (Explorer)**:
   * Быстрый переключатель активного хаба: `00-Inbox`, `10-System`, `20-Work`, `30-Life`, `40-Resources`.
   * Дерево файлов и папок текущего хаба.
   * Поле быстрого поиска (Ctrl+P / Command Palette).
2. **Center Panel (Document Workspace)**:
   * Заголовок документа, путь, теги из Frontmatter.
   * Переключатель режимов: Preview (чтение) / Edit (редактирование Markdown).
   * Поддержка горячих клавиш (Ctrl+S для сохранения).
3. **Right Panel (AI Assistant)**:
   * Сворачиваемая панель чата с ассистентом.
   * Поле ввода с автоматическим перехватом `{{secret:пароль}}`.
   * История контекстных диалогов по открытой заметке.

---

## 2. Secret Pill Widget (Виджет отображения секретов)
Когда рендерер Markdown встречает токен вида `🔒[enc:v1:...]`:
* Вместо сырого шифротекста рендерится интерактивный компонент `SecretPill.svelte`:
  * Состояние по умолчанию: `••••••••••••` (звездочки).
  * Кнопка **👁️ Показать**: Запрашивает расшифровку (или ввод пасс-фразы, если ключ не разблокирован) и показывает текст на 15 секунд.
  * Кнопка **📋 Копировать**: Расшифровывает значение и копирует прямо в системный буфер обмена без отображения на экране.

---

## 3. Pre-Send Prompt Interceptor (Перехватчик промптов)
В поле ввода ассистента:
* Перед отправкой сообщения в бэкенд фронтенд выполняет регулярное выражение:
  `/\{\{secret:(.*?)\}\}/g`
* Для каждого найденного вхождения вызывается `crypto_encrypt_secret(match)`:
  * Исходный пароль локально превращается в `🔒[enc:v1:...]`.
* Агенту отправляется уже санитизированный промпт без открытых секретов.
