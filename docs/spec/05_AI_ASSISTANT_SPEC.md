# CORTEX: AI Assistant & Blind Agent Specification

## 1. Концепция «Слепого агента» (Blind Agent)
Агент — это внешняя языковая модель (Gemini / Antigravity / Claude / локальная модель), которая:
1. Помогает структурировать информацию, писать скрипты, составлять саммари, отвечать на вопросы по базе.
2. **Не имеет доступа к открытым секретам**:
   * При чтении заметок видит `🔒[enc:v1:...]`.
   * При формировании ответа может переносить, копировать или организовывать токен в таблицах, но не знает его содержимого.
   * Не может выполнить расшифровку (у агента нет доступа к приватному ключу и пасс-фразе пользователя).

---

## 2. Tools (Инструменты агента в Cortex)
Агент оснащается локальными инструментами через стандартный протокол Function Calling:
* `vault_search(query: string)` — поиск по заметкам и тегам.
* `vault_create_note(path: string, content: string)` — создание новой заметки в хабе.
* `vault_update_note(path: string, diff: string)` — внесение изменений в существующую заметку.
